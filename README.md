# Car Crash

A 3D endless car driving game built in Unity where the player drives through traffic and earns cash to buy new cars.

## About the Game
Car Crash is a 3D endless driving mobile game. The player drives through traffic and earns cash by scoring points. Use the cash to buy new cars from the garage shop and keep driving.

## Gameplay
- Drive through **traffic** without crashing
- Earn **cash** by scoring points
- Visit the **garage shop** to buy new cars
- Drive as long as possible

## Features
- Endless driving gameplay
- Traffic spawning system
- Cash and score system
- Garage and shop system
- Car selection system
- Mobile-ready controls

## Built With
- **Engine:** Unity
- **Language:** C#
- **Platform:** Mobile (Android)
